# 3X-UI

**3X-UI** — веб-панель управления Xray-core с веб-интерфейсом, управлением входящими подключениями, клиентами, подписками, маршрутизацией, узлами и настройками панели.

Этот репозиторий — форк проекта **3X-UI** с русским языком интерфейса по умолчанию и обновлённым UI на основе Material 3. Английский язык остаётся доступным в интерфейсе.

> [!IMPORTANT]
> Проект предназначен для личного использования и тестирования. Перед использованием на реальном сервере самостоятельно проверьте конфигурацию, безопасность и совместимость окружения.

## Возможности

- Управление конфигурацией Xray-core и входящими подключениями.
- Управление клиентами, лимитами трафика, сроком действия и IP-ограничениями.
- Статистика трафика и управление узлами.
- Подписки и REST API.
- SQLite по умолчанию и PostgreSQL для альтернативного хранения данных.
- Интеграции с Telegram, Discord и Fail2ban.
- Два варианта MTProto-прокси: встроенный `mtg` для MTProto-inbound и отдельный Telemt как самостоятельный сервис.
- Адаптивный интерфейс с навигацией Material 3.
- Темы: светлая, тёмная, ultra-dark, colorful и blue-gray.
- Русский интерфейс по умолчанию; английский — дополнительный язык.
- Поддержка низкоресурсного профиля для Arch Linux.

## Быстрый старт

### Установка

Установочный скрипт находится в этом репозитории:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/SawaMEN/3x-ui/main/install.sh)
```

> [!NOTE]
> Текущий `install.sh` использует релизные архивы и связанные файлы из upstream-репозитория **MHSanaei/3x-ui**. Поэтому команда выше устанавливает актуальную upstream-сборку, а не отдельный бинарный релиз этого форка.

Для установки конкретной версии upstream:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/SawaMEN/3x-ui/main/install.sh) v3.8.5
```

Для rolling dev-сборки:

```bash
bash <(curl -Ls https://raw.githubusercontent.com/SawaMEN/3x-ui/main/install.sh) dev-latest
```

После установки управление панелью доступно через команду:

```bash
x-ui
```

Установщик генерирует или принимает параметры учётной записи и сохраняет результат установки в защищённом файле `/etc/x-ui/install-result.env`.

### Ручная разработка

Frontend требует **Node.js 24+** и **npm 10+**. Версия Node закреплена в `.nvmrc`.

Основные команды frontend:

```bash
cd frontend
npm install
npm run typecheck
npm run lint
npm run test
npm run build
```

Для форматирования:

```bash
npm run format
npm run format:check
```

## Поддерживаемые архитектуры установщика

Установщик определяет архитектуру автоматически и поддерживает:

- `amd64`
- `x86` (в сборках используется `386`)
- `armv8` (в сборках используется `arm64`)
- `armv7`

Установщик рассчитан прежде всего на Linux-системы. Для конкретной ОС проверяйте логику `install.sh` и соответствующий systemd/OpenRC unit.

Telemt сейчас поставляется вместе с релизами для `amd64` и `armv8` (`x86_64`/`aarch64`). На `armv7` и `x86` (`386`) Telemt в пакет не включается, поэтому там остаётся встроенный MTProto через `mtg`.

## Базы данных

По умолчанию используется **SQLite**.

Для PostgreSQL можно задать:

```bash
XUI_DB_TYPE=postgres
XUI_DB_DSN=postgres://xui:password@127.0.0.1:5432/xui?sslmode=disable
```

## Arch Linux

Для Arch Linux предусмотрен отдельный systemd unit и профиль установки.

Установщик использует полное обновление `pacman -Syu`, чтобы не выполнять неподдерживаемые partial upgrades.

Профиль низкого потребления ресурсов использует:

- `GOMAXPROCS=1`;
- `GOMEMLIMIT=256MiB`;
- `GOGC=80`;
- `CPUQuota=100%`;
- `MemoryHigh=384M`;
- `XUI_LOW_RESOURCE=true`.

Это консервативные значения для небольших VPS, а не гарантия максимального потребления памяти всем стеком Xray/3X-UI.

Подробности: [docs/archlinux.md](docs/archlinux.md).

## Язык интерфейса

Русский (`ru-RU`) — основной язык интерфейса.

Английский (`en-US`) — дополнительный язык.

Если язык браузера не поддерживается, интерфейс автоматически использует русский.
