## Исправления и удаление лишнего

Docker использовал Node 26 при `.nvmrc=24`, скачивал несовместимый внешний
latest kernel и устанавливал старый `mtg-multi` вместо действующего Telemt.
`DockerInit.sh` также не имел executable bit для `RUN ./DockerInit.sh`.
Теперь образы Go/Node/Alpine зафиксированы digest; ядро строится из того же
закреплённого исходника с overlays, что проверяется панелью; используются
официальный Telemt и broker-совместимый Mieru. Удалены obsolete MTG-загрузчик,
молчаливый fallback неизвестной архитектуры на amd64 и лишние переменные.
Добавлены `.dockerignore` и кеши npm/Go. Неподдерживаемая архитектура завершается
явной ошибкой до скачивания компонентов.

Release arm64 переведён с кросс-компиляции на настоящий ARM runner. Обязательная
Go-матрица конфигураций исполняется на обеих архитектурах; missing/skip/fail
требуемого теста больше не может дать успешный gate. Пакет получает manifest
с размерами, режимами, SHA256, source revision и Go build info. Проверяются
архитектура ELF, статическая линковка панели/ядра, kernel lock/profile,
совпадение версии и SHA и отсутствие неожиданных symlink.

При нативном прогоне первая версия исправлений выявила собственные недочёты:
x86-host Bootlin compiler не исполняется на ARM, копирование ядра под именем
`core` нарушало ожидаемое имя для identity probe, а ожидание полностью
статического ELF не соответствовало default purego/libcronet profile.
Эти неудачные прогоны сохранены как неудачные, а не исключены из отчёта.

Для переносимого release выбран статический musl/Cronet profile, который
уже прошёл обе архитектуры в Alpine. Сборка этого профиля Ubuntu-компилятором
дала segmentation fault при старте первого native теста. Поэтому выделен
общий Docker target `kernel`: Docker и release используют один проверяемый
Alpine-рецепт. Удалён загрузчик/HTML-scraper Bootlin toolchain. Отдельный
`libcronet.so` в статическом пакете не нужен и запрещён как stale dependency.
Нативные тесты не отключались для обхода ошибки.

Dev-публикация ранее доверяла только имени автора, заголовку форматирующего
коммита и пути файла. Теперь дополнительно сравнивается фактический canonical
output lockfile-pinned oxfmt до/после изменения. Обычный код, замаскированный
ботовым metadata, не позволяет переиспользовать старую сборку. Тесты используют
настоящий временный Git remote и fake `gh`; старый дублирующий mocked-Git тест
удалён. Проверяются current head, divergence, application change, форматирование,
маскировка изменения, отсутствие formatter и изменение вне frontend.

Stable-версия обязана точно совпадать с числовым tag; prerelease не может
публиковаться как stable. Branch build обязан точно показывать `dev+<sha8>`.
Устаревшие push-builds `main`/`update` отменяются, version-tag/manual builds
этим условием не отменяются. `update` не публикует stable или dev-latest.
Проверка публикации выполнялась на локальных временных remotes; реальные
пользовательские теги/релизы не создавались.

## Зависимости и безопасность

Обновлены `golang.org/x/net` до `v0.62.0` в панели и kernel build lock,
Swagger UI и ограниченный override minimatch в Swagger resolver; в docs —
Next 16.4.1, Mermaid 12.2.0, Zod 4.6.6 и уязвимые транзитивные зависимости.
Для точной старой зависимости undici используется scoped override 7.30.1.
Typecheck/tests/build docs после обновлений прошли на CI.

- Docs production audit: **0** записей вместо исходных 25.
- Frontend production audit: **3 low** записи вместо исходных 5; это один
  unresolved upstream deepmerge advisory и два зависимых Swagger-пакета,
  а не три независимо обнаруженные ошибки приложения. Исправленной версии
  upstream deepmerge в проверенном registry нет. Viewer использует фиксированную
  сгенерированную схему панели; произвольная schema URL не включена. Остаточный
  риск зависимости сохранён для API/security этапа, audit не объявлен нулевым.
- `govulncheck -show verbose ./...`: **0 достижимых уязвимостей**, 0 на уровне
  импортируемых packages; остаётся module-level сообщение об unused/unmaintained
  OpenPGP внутри `x/crypto`. Сам модуль нужен другим crypto packages; удалять
  его целиком ради исчезновения сообщения неверно.
- Gitleaks 8.30.1: **68** redacted срабатываний в истории с merge diff,
  **132** в текущем дереве. Triage по fingerprint: тестовые/документационные
  примеры и ложные срабатывания на названия алгоритмов/параметры AWG.
  Blanket allowlist не добавлен, credentials через внешние сервисы не проверялись.

Дополнительный анализ готовых kernel ELF обнаружил сведения, которых не было
в анализе одной панели: `GO-2026-6809` в x509 Go 1.26.9, старые CEL/Chi и
консервативное wildcard-сообщение OpenPGP. Поэтому compiler ядра обновлён
до Go 1.26.10, Chi — до 5.3.0, CEL — до 0.30.0. Версия сборки получила `sec1`.
Уязвимая `x509.Certificate.Verify` присутствовала в ELF; `RealIP`, `NativeTypes`,
`ParseStructTag` и OpenPGP не были найдены в исходных вызовах/таблице имён
бинарника. Обновления Chi/CEL также устраняют зависимости от старых версий.

Бинарный mode может консервативно сообщать о wildcard-packages без точной
достижимости. Для точного scope CI теперь запускает source govulncheck на
подготовленном `./cmd/main` с фактическими tags, CGO profile и Go compiler,
и отдельно запрещает появление deprecated OpenPGP в графе импортов. Модуль
`x/crypto` сохраняется для реально используемых crypto packages. Локальная
пересборка security profile прошла native unit checks и 10/10 constructor
checks; её source-аудит — 0 достижимых и 0 package-level уязвимостей.
Четыре финальных binary scans (панель/ядро × amd64/arm64) вернули **exit code 3**,
единственный advisory — `GO-2026-5932`. Это не нулевой результат сканера.
Triage: OpenPGP отсутствует в графе импортов и таблице имён ELF; source-аудит
точного профиля обеих архитектур — 0 affected/0 package-level. Suppression не добавлен.

Число advisory/scan-записей не используется как число исправленных ошибок.
Security scans подтверждают проверенный scope и не доказывают отсутствие
всех уязвимостей, особенно в C/C++ зависимостях.

## Полнота исполнения и ограничения

`make verify` включает codegen freshness, оба линтера/deprecated APIs,
format/typecheck, MSW worker, Go/frontend suites, production и Storybook build.
В frontend: **271 файл, 2373 passed, 1 conditional native skip**. Это тест
импорта HY2 JSON с реальным ядром; release теперь обязан повторить весь его
файл на каждой архитектуре с предоставленным бинарником и нулём skipped.
Финальный replay прошёл: **28/28 tests файла на каждой архитектуре**, без skip.
HY2-тест перебирает три JSON-конфигурации; это не 28 сетевых handshake.
Обязательные Go constructors: девять сценариев и родительский тест —
**10 успешных событий на каждой архитектуре**, без skip. Go env-dependent tests,
которые принадлежат сетевым/DB этапам, не объявляются выполненными одной сборкой.

Локально прошли 33 management + 33 migration shell tests и 16 gate/publication/
version tests. Полный локальный make verify ранее упирался в запрет enumeration
сетевых интерфейсов Storybook; одновременные lint/docs build также превысили
местные 8 GiB. Эти попытки не зачтены как pass. Полный gate выполнен на CI.

Архив свидетельств содержит CI states/log excerpts, source/build locks,
результаты audits и triage, а также независимый ZIP → tar → manifest → ELF
verifier. Артефакты и их source SHA проверяются отдельно от состояния
последующего документационного коммита. Полная работоспособность протоколов,
миграции данных и восстановление остаются этапами 3–14.
