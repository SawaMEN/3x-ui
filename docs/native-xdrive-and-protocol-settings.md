# Нативный XDrive и настройки протоколов

Исходная панель сверена с MHSanaei/3x-ui `c621ba9014a6aa21fd7c9ecf45655e44e24ebf13`
(v3.11.0). На момент сверки более новых коммитов в её main нет. Предыдущий
перенос перечислен в `upstream-v3.11.0-port.md`; эта доработка закрывает
отдельно пропущенный XDrive и несоответствия форм нативному ядру.

## XDrive

XDrive работает внутри SawaMEN/hiddify-sing-box, без отдельного процесса Xray.
Панель закрепляет ревизию ядра в `hiddify-core-target.json`, а сборщик проверяет
наличие транспорта и запускает его тесты вместе с существующими проверками ядра.

- Входящие → VLESS → транспорт XDrive. Нужен новый билд ядра из lock-файла.
- Включить VLESS encryption и сгенерировать пару ключей. Flow и TLS вокруг
  туннельного потока не используются. HTTPS к API хранилища проверяет сертификат
  обычным способом; front-address меняет адрес соединения, сохраняя имя API.
- Поддержаны local, Google Drive, HTTP templates и S3. Для local оба процесса
  должны видеть одно хранилище. Google Drive использует folder ID и три секрета
  (Client ID, Client Secret, Refresh Token); S3 — endpoint, bucket и ключи.
- Параметры сегментов, polling, flush, TTL, concurrency, шаблон и XMUX
  передаются из формы в нативный transport, без подмены TCP-профилем.
- TCP/UDP listener не создаётся. Автосинхронизация firewall не открывает
  фиктивный входящий порт для этого транспорта.
- Нужна JSON-подписка (`format=hiddify` для собственного нативного ядра,
  `format=xray` для Xray). Hiddify User-Agent выбирает нативный формат
  автоматически; stock sing-box не получает неподдержанный transport.
  JSON выдаёт каждому клиенту общую папку и секреты
  хранилища. Обычная VLESS-ссылка и Clash-профиль XDrive не описывают; панель
  не выдаёт вместо них неполную рабочую на вид конфигурацию.
- Xray JSON получает необходимый Mux.Cool, нативный JSON — обычный encrypted
  VLESS stream, без подмены Mux.Cool несовместимым sing-mux.

В ядре HTTP-запросы используют нативный dialer, включая detour, DNS и привязки.
Ошибка detour не приводит к прямому соединению. HTTP pool принадлежит одному
transport и закрывается при остановке. MPL-2.0-файлы wire/storage реализации
сохраняют лицензию и ссылку на исходный Xray commit.

## Hysteria

Форма поддерживает версии 1/2, скорость, BBR profile, Salamander/Gecko,
пароль обфускации и размер пакетов Gecko. Для Hysteria 2 пустая/нулевая скорость
оставляет автоматическое управление; Hysteria 1 требует положительной скорости.
Ограничение общей скорости транспорта не заменяет лимит клиента по подписке.

Редактирование не удаляет нативные поля и расширения. Snake-case aliases
нормализуются к форме, чтобы изменённая скорость не перекрывалась старым alias.
Неверные параметры сохраняются для исправления и валидации вместо молчаливой
замены всей конфигурации значениями по умолчанию.

`udpIdleTimeout`, masquerade и ignore-client-bandwidth относятся к серверу.
Они больше не копируются в клиентский JSON. Исправлена ошибка, из-за которой
нестандартный UDP timeout делал нативную подписку невалидной. В исходящей форме
серверные настройки не предлагаются. Версия в settings и transport согласуется.
Xray-only insecure/X-Forwarded для masquerade отмечаются и могут быть сброшены.

## MASQUE

Сохранена нативная модель CONNECT-IP, HTTP/1.1/2/3, автоматический сертификат,
WARP и расширенные HTTP/QUIC параметры. В форме доступны также routing mark,
UDP fragmentation, TCP Fast Open, Multipath TCP и reuse-address. Числовые поля
используют диапазоны ядра, включая packet size 1200–65527, а подписи переведены.
Переключение HTTP-версий сохраняет значения, отключая неприменимые поля.

## Проверки и границы

- Native XDrive: шифрованный VLESS с проверкой пользователя, крупный
  двунаправленный поток, slots, отмена контекста подключения без потери
  установленного соединения, закрытие активных потоков,
  native dialer/failure, JSON codec; пять повторных race-прогонов и
  проверки VLESS/VMess/Trojan.
- Проверка transport wire interoperability с исходным Xray в обе стороны
  через независимые исполняемые файлы (`tools/test-xdrive-interop.py` в ядре).
- Регрессии backend-перевода и подписок; формы edit/save, aliases и сохранение
  секретов; typecheck и production frontend build.
- Внешние Google Drive/S3 аккаунты и их реальные разрешения не проверялись.
  Проверка local transport не является проверкой доступности облаков у операторов.

Это не перенос всего runtime Xray: его gRPC-процесс, Lua DNS/routing и другие
отдельные API не появляются от копирования формы. Их прежние архитектурные
ограничения не следует считать снятыми реализацией XDrive.
