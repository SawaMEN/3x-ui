# Функциональный аудит 3x-ui — 28 октября 2026

База: `main`, `7e48fc608ec39001c175d7eb4174e4a716df92da`.

Запрошенная цель — найти и исправить 200 ошибок. В этом наборе подтверждены
**12 отдельных причин сбоев**. Это не заявление о завершении всей цели:
оставшиеся 188 ошибок не установлены. Прошедшие тесты, новые входы фаззинга,
отдельные протоколы и разные проявления одной причины не считаются ошибками.

## Проверки и границы

- Базовые пакеты Go: `internal/database/...`, `internal/clientlimit/...`,
  `internal/util/...`; пакет `internal/sub`.
- Целевые тесты сервисов клиентов, групп, пагинации, настроек и продления;
  повторная проверка с детектором гонок.
- Frontend: 1 574 unit-проверки, 614 компонентных проверок; после последних
  изменений расчёта протоколов дополнительно 21 целевая проверка.
- Фаззинг `FuzzParseLink`: 30 секунд, 980 393 выполнения, без сбоев.
- TypeScript, frontend lint/форматирование, Go lint; сборки Vite и Storybook.

Полный `make verify`/GitHub CI не запускался: ранее автоматическая проверка
разрешений отклонила обращение полного набора к `api4.ipify.org`, поскольку оно
раскрывает публичный IP среды. Этот аудит не обходил отказ. CI при публикации
этого набора пропускается через `[skip ci]`; результат не следует считать
прохождением полной матрицы. Live PostgreSQL и полный набор браузерных историй
Storybook в этом аудите также не проверены.

Дополнительно устранён найденный сбой обязательного `lint:deprecated`: поле
`AutoComplete.filterOption` в настройках перенесено в поддерживаемый
`showSearch.filterOption`. Это исправление совместимости не добавлено к счётчику
функциональных ошибок.

Данные существующей установки и рабочие серверы пользователя не изменялись.
Изменения подготовлены в отдельной ветке для проверки.
