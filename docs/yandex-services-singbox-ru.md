# Яндекс-сервисы в штатном модифицированном sing-box

## Доступные интеграции

Панель 3x-ui создаёт конфигурацию штатного транспорта XDRIVE для **модифицированного sing-box**. Не требуется отдельное VPN-ядро, но сборка sing-box должна понимать `transport.type=xdrive`, `template` и/или `s3`. Обычный upstream sing-box без этих расширений может не принять конфигурацию.

| Сервис | Интеграция | Как использовать | Ограничения |
| --- | --- | --- | --- |
| Яндекс Диск WebDAV | XDRIVE template, штатная адаптация sing-box в панели | Логин + пароль приложения, проверка операций и автосоздание рабочей папки | Яндекс 360, высокая задержка и ограничения запросов |
| Яндекс Диск REST API | XDRIVE template с OAuth и двухэтапным `href` | Создать OAuth-приложение и папку, ввести токен; шаблон генерируется автоматически | Выдача списка в пресете до 1000 файлов; на `href` задействуются дополнительные домены |
| Yandex Cloud Object Storage | XDRIVE S3 | Создать бакет и сервисный аккаунт со статическим ключом | Это *не* личный Яндекс Диск, тарификация и другие хосты |
| Яндекс Документы (классический редактор) | OpenFlux `yandex` | Настроить из карточки OpenFlux | **Не нативный** транспорт sing-box |
| Яндекс Документы (Volga) | OpenFlux `vyandex` | Настроить из карточки OpenFlux | **Не нативный** транспорт sing-box |
| Яндекс Доски | OpenFlux `boards` | Настроить из карточки OpenFlux | **Не нативный** транспорт sing-box |
| Яндекс Телемост | OpenFlux `telemost` | Настроить из карточки OpenFlux | **Не нативный** транспорт sing-box |

Почта, Карты, Поиск, Музыка и другие веб-сервисы без документированного API чтения/записи файлов **не могут автоматически считаться XDRIVE-транспортами**. Присутствие домена в белом списке не означает пригодности сервиса для туннелирования. Для каждого дополнительного сервиса нужна отдельная архитектура транспорта, тесты и проверка правил использования.

## Быстрая настройка

1. В панели выбрать ядро **модифицированный sing-box**, затем добавить входящее подключение **VLESS** с транспортом **XDRIVE**.
2. В разделе «Яндекс-сервисы для sing-box / XDRIVE» выбрать Яндекс Диск WebDAV, REST API или Yandex Cloud Object Storage.
3. Заполнить только учётные данные. Веб-интерфейс сам подставит адреса API, запросы хранения, параметры XDRIVE и S3 (где применимо).
4. Для WebDAV нажать **«Проверить доступ и подготовить папку»**: панель проверит авторизацию и операции PUT/GET/PROPFIND/DELETE, не затрагивая другие файлы.
5. На входящем VLESS включить пользовательское шифрование VLESS; `flow` использовать нельзя. В клиенте требуется такое же хранилище и корректная JSON-подписка с настройками XDRIVE и поддержкой VLESS Encryption/Mux.
6. Проверить **реальное соединение с другого устройства**, затем отдельно провести проверку при белых списках мобильного оператора.

**Важно:** кнопка тестирования проверяет доступ **от сервера к Яндексу**, а не достижимость API с телефона у МТС, МегаФона, Билайна или T2.

## Безопасность и ограничения

- Создавайте отдельный аккаунт Яндекса либо сервисный аккаунт с минимальными правами и без личных файлов.
- Секреты XDRIVE передаются в JSON-конфигурации клиента. Любой получатель подписки получит доступ к общему хранилищу — не публикуйте подписку или пароль приложения.
- Хранение VPN-данных через публичные API может быстро расходовать квоты файловых операций. Высокая задержка нормальна.
- В исходящем узле **нет необходимости открывать входящий порт** для XDRIVE, но VPS должен иметь исходящий HTTPS-доступ к API хранилища.
- Серверный тест **не подтверждает**, что API доступен во время ограничений мобильного интернета, что клиент совместим с конфигурацией или что провайдер допускает такой сценарий.
