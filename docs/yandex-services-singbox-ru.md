# XDRIVE в модифицированном sing-box: Яндекс Диск и Object Storage

Встроенный в 3x-ui мастер **XDRIVE** создаёт настройки транспорта в конфигурации выбранного **модифицированного sing-box**. Он не устанавливает другие VPN-ядра и не подключает внешние транспорты. OpenFlux — отдельный компонент, **не часть XDRIVE**.

## Поддерживаемые хранилища

| Вариант | Данные для подключения | Автоматизация |
| --- | --- | --- |
| **Яндекс Диск — WebDAV** | Логин Яндекс ID, отдельный пароль приложения, тариф Яндекс 360 с WebDAV | Заполняет шаблон HTTP/WebDAV, может создать рабочую папку и проверить загрузку/чтение/листинг/удаление тестового файла |
| **Яндекс Диск — REST API** | OAuth-токен приложения с правами чтения/записи | Заполняет REST-шаблон и временные ссылки; может создать папку и проверить файловые операции |
| **Yandex Cloud Object Storage — S3** | Существующий бакет, ID и секрет статического ключа сервисного аккаунта | Заполняет endpoint, регион, path-style, префикс объектов; проверяет S3 ListObjectsV2/PUT/GET/DELETE без создания бакета |

S3 Object Storage — **отдельный платный сервис Yandex Cloud**, а не обычный Яндекс Диск. Указание домена хранилища в списке разрешённых адресов оператора не подтверждает доступности S3 API в конкретной мобильной сети.

## Настройка в панели

1. Выберите модифицированный **sing-box** с поддержкой `transport.type=xdrive`, затем добавьте входящее подключение **VLESS** с транспортом **XDRIVE**.
2. В списке «Облачное хранилище Яндекса» выберите **WebDAV**, **REST API** или **Object Storage**. Поле «Сервис хранилища» и остальные низкоуровневые параметры мастер задаёт сам.
3. Нажмите на знак **«?» рядом с каждым полем**, если нужны пояснения. Ссылки рядом с настройками ведут к официальным инструкциям по получению паролей приложений, OAuth-токенов и статических ключей S3.
4. Выберите имя рабочей папки или нажмите **«Сгенерировать отдельную папку»**. Для Object Storage это виртуальный префикс внутри бакета — отдельное создание папки в облаке не требуется.
5. Нажмите **«Проверить подключение и доступ к файлам»**. Проверка выполняется **с сервера, на котором запущена панель**; на удалённых нодах мастер её пока не запускает. Проверка использует временный объект и удаляет его.
6. Сгенерируйте VLESS Encryption в панели, не задавайте `flow`, настройте совместимого клиента с корректной JSON-подпиской XDRIVE и необходимыми параметрами мультиплексирования. Только после этого проверьте полный туннель с другого устройства.

**Подсказка:** параметры фронтинга, размеры сегментов, опросы и параллелизм находятся в раскрывающейся секции **«Дополнительные параметры XDRIVE»**. Для первой настройки оставьте их без изменений.

## Яндекс Диск WebDAV

- [Подключение через WebDAV](https://yandex.ru/support/yandex-360/customers/disk/web/ru/webdav): требуется соответствующий тариф Яндекс 360.
- [Пароль приложения](https://id.yandex.ru/security/app-passwords): создайте отдельный пароль приложения именно для Диска. Не вводите основной пароль от аккаунта.
- Хранение осуществляется через `https://webdav.yandex.ru`. Мастер автоматически вставляет команды `PUT`, `GET`, `PROPFIND`, `DELETE`.
- При проверке создаётся отдельная папка (если её нет), затем временный файл записывается, читается и удаляется.

## Яндекс Диск REST API

- [REST API Диска](https://yandex.ru/dev/disk/rest/) и [документация авторизации](https://yandex.ru/dev/disk-api/doc/ru/concepts/quickstart).
- Требуется OAuth-токен приложения с разрешениями работы с файлами. Он не равен паролю Яндекса и не является ссылкой на опубликованный файл.
- Мастер использует `https://cloud-api.yandex.net/v1/disk`, двухэтапные загрузки и скачивания по временным `href`, которые могут указывать на другие HTTPS-хосты. При мобильных белых списках доступ к одному API-хосту **не гарантирует** работу транспорта.
- Текущая конфигурация XDRIVE запрашивает до **1000 имён** за одно перечисление. Для долгоживущего интенсивного соединения это ограничение требует отдельного испытания и, возможно, поддержки пагинации в XDRIVE.

## Yandex Cloud Object Storage — S3

- [Создать бакет](https://yandex.cloud/ru/docs/storage/operations/buckets/create), [создать статический ключ доступа](https://yandex.cloud/ru/docs/iam/operations/authentication/manage-access-keys).
- Endpoint: `https://storage.yandexcloud.net`, регион подписи: `ru-central1`, адресация: `path-style`. Эти параметры подставляются автоматически.
- Заполняйте только **имя бакета**, **ID статического ключа**, **секрет статического ключа** и **префикс объектов**. Записи проверяются только внутри префикса.
- Тест сначала проверяет разрешение `ListObjectsV2`, затем создаёт тестовый объект, читает и перечисляет его, удаляет. Если нет прав на эти операции, настройка не считается проверенной.
- Создание бакета не автоматизировано: это отдельная оплачиваемая облачная операция, которую необходимо подтвердить в консоли.

## Безопасность и диагностика

- Для WebDAV используйте отдельный аккаунт без личных файлов; для S3 — выделенный сервисный аккаунт с правами только на нужный бакет/префикс.
- JSON-подписки XDRIVE содержат секреты хранилища. Не публикуйте их; выдавайте доступ только доверенным клиентам.
- При неуспешной проверке учитывайте код ошибки: `401` — неправильная авторизация; `403` — недостаточно прав; `404` — неверный бакет/путь; `429` — ограничение запросов.
- Все диагностические запросы отправляются только на фиксированные API Яндекса; сервер не принимает произвольный адрес хранилища от пользователя для этих тестов.
- Успех проверки доказывает только доступ **от VPS к хранилищу**. Он **не доказывает** доступ с телефона при белых списках, работоспособность клиентского XDRIVE или скорость/стабильность туннеля.
