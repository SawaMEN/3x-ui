# Проверка ограничений Mieru, Sudoku и MASQUE

Работа выполнена поверх `1ed4587dde518105479d1bc7490c09bd13ed9487`.
Проверки реализации выполнены 27–28 октября 2026 года.

## Изменение

Все три протокола используют общий бюджет записи клиента в панели. Одновременные
подключения через VLESS и новые протоколы не получают отдельный полный лимит.
Внешние процессы запрашивают разрешение на передачу байтов через аутентифицированный
loopback-канал; полезный трафик через этот управляющий канал не проходит.

Патчи Mieru/Sudoku и MASQUE закреплены в `deploy/speed/`. В релизные пакеты
включаются совместимые серверы и ядро. Протоколы на проводе не изменены;
обновление клиентских приложений для этого механизма не требуется.

Первое включение, изменение и удаление ограничений Mieru/Sudoku проходят через
существующий runtime и пакетное применение конфигурации. Затронутые процессы
останавливаются до смены плана, ключи Sudoku сохраняются. Согласование состояния
не запускает ограничиваемый sidecar без опубликованного бюджета.

## Выполненные проверки

- Race-тесты общего бюджета: TCP и три группы нативных идентификаторов совместно
  используют 1 Мбит/с, независимый пользователь не ограничивается этим бюджетом.
- Авторизация, отмена, закрытие соединений, откат плана, права файла 0600,
  стабильный путь конфигурации и восстановление после ошибки хранения.
- Runtime-тесты первого включения лимита из клиентского payload и единственного
  применения после завершения пакета изменений. Старые сценарии без лимитов
  Mieru/Sudoku сохраняются.
- Генерация конфигурации, canonical snapshot для sidecar-клиентов и отсутствие
  повторного пропускания нативного трафика через обычный SOCKS-ограничитель.
- Новые проверки бюджета и первого включения отдельно запускались с отключёнными
  исправлениями через Go overlay и завершились ожидаемыми ошибками.
- `golangci-lint run`: без замечаний после форматирования.
- TypeScript, frontend lint/format и пять тестов формы клиента, включая сохранение
  лимитов Mieru/Sudoku/MASQUE. Vite и Storybook успешно собраны.
- Mieru и Sudoku собраны заново из закреплённых исходников с применением патчей
  через `tools/build-speed-components.py`; сформирован манифест SHA-256.
- Полное ядро собрано через `tools/build-hiddify-core.sh`, включая существующие
  overlay-проверки, CLI check/version и runtime Cronet. MASQUE transport/protocol
  unit-тесты изменённого исходника пройдены.
- Живые проверки Sudoku с настоящими сервером и клиентом: TCP, MUX, HTTPMask,
  сохранение TCP/UDP payload и фактическое ограничение скорости.

## Неподтверждённые сценарии

Живой прогон `mita` в этой среде заблокирован запретом Unix-domain sockets.
Для MASQUE HTTP/1, HTTP/2 и HTTP/3 среда запрещает netlink, необходимый сетевому
монитору ядра. Эти пропуски не засчитываются как успешная проверка ограничения
скорости. В CI добавлен отдельный native-client-speed job для обычного Linux runner.

Полный `make verify` был остановлен автоматической проверкой разрешений: общий
набор тестов может обращаться к `api4.ipify.org` и раскрывать публичный IP среды.
Это обращение не обходилось. Локальные проверки выше выполнялись отдельно.
Полный CI намеренно отложен; в этой ветке используется отметка пропуска CI до
отдельного разрешения на этот полный прогон. Не сливайте ветку как прошедшую
полную матрицу, пока пропуски и полный CI не будут закрыты.
