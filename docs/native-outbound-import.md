# Native outbound import

The outbound dialog and the list's Import action use the installed owner kernel's
`parse` command. The parser is bounded by request cancellation, a 15 second timeout,
and a 1 MiB input limit. Temporary files are private and removed after parsing.
Credential-bearing parser diagnostics are never logged or returned.

## Supported formats

- Standard share links understood by the installed kernel, including its native
  codecs for Mieru, Snell, TrustTunnel, Sudoku, FPTN, OpenFlux and Pingtunnel.
- Proxy chains (`link -> link`) and multiple links. All nodes and endpoint nodes
  are retained; tag collisions are resolved together with detour/group references.
- One native connection, an array of connections, or a native configuration's
  `outbounds` and `endpoints` sections.
- `singbox://BASE64URL_UTF8_JSON` (also `sing-box://`), generated by **Получить ссылку**.
  This format supports every native type/option without a panel whitelist, including
  future kernel additions and protocols that have no conventional share URI.
- Typed native URL parameters, including camelCase/snake_case aliases and dotted
  paths such as `tls.server_name` or `transport.xmux.max_concurrency`.
- `options={JSON}` / `native={JSON}` overlays for arbitrary native fields. Nested
  objects merge without losing existing TLS/transport data. A link cannot override
  its decoded type/tag through an overlay.

Native scalar type information is generated from the owner Sing-box option
structs and the panel's kernel build overlays by:

```
python3 tools/generate-native-import-options.py /path/to/hiddify-sing-box
```

Canonical native JSON is never narrowed by this snapshot. The installed kernel
and the full configuration validator remain authoritative for supported settings,
required secrets, dependent groups/endpoints and valid protocol combinations.

## Audited kernel

Stable release `sawamen-22fb84fdd93a-3827d3a871dd-panel8`; owner Sing-box revision
`3827d3a871dd3bcc7e8265538df7ceb157dd0066`, including the build's reverse, transport,
TLS and balancer overlays. The Linux AMD64 binary was downloaded with SHA-256
verification together with its matching Cronet dependency.

| Category | Native types |
| --- | --- |
| Proxy protocols | socks, http, shadowsocks, snell, vmess, trojan, naive, ssh, shadowtls, vless, anytls, mieru, sudoku, openflux, fptn, pingtunnel, trusttunnel, hysteria, hysteria2, tuic |
| Other outbounds | direct, bridge, block, selector, urltest, balancer, tor, psiphon, xray, dnstt, gooserelay, masque, tailcat, vless-reverse, wireguard_legacy |
| Endpoints | wireguard, awg, warp, tailscale, openconnect, openvpn-client, openvpn-server, masque-client, masque-server, tunnel_client, tunnel_server |
| Transports | TCP, raw, HTTP, WebSocket, gRPC, HTTPUpgrade, XHTTP, QUIC, mKCP |
| VLESS encryption | none; mlkem768x25519plus with native/xorpub/random, 0rtt/1rtt, padding and server keys |
| Final masks | TCP: header-custom, fragment, sudoku, xmc. UDP: header-custom, mkcp-legacy, noise, salamander/Gecko, sudoku, xdns, xicmp, realm. Mask settings/chains are retained in final_mask. |

The retired `shadowsocksr`, DNS outbound and removed `wireguard` outbound stubs
are not advertised as working proxy types. WireGuard uses the endpoint section;
the explicitly named `wireguard_legacy` wrapper remains available where the owner
kernel actually registers it.

The owner kernel's legacy URI converter currently misses mKCP and generates an
empty host-key entry for password-only SSH links. The panel supplies narrow
adapters for these cases, retaining native mKCP tuning/header/seed/masks and SSH
password/key/host-key options. Legacy `xtls-rprx-vision-udp443` becomes native
Vision with XUDP. Other valid VLESS encryption strings are preserved verbatim.

## Verification

- Lossless raw JSON/universal-link import for every listed native type, including
  arbitrary nested settings and UTF-8 names.
- Real stable-kernel parse/check cases for encrypted VLESS, Vision + encryption,
  XHTTP, mKCP, masks, VMess, Trojan, HTTP/SOCKS, Hysteria/Hysteria2, Mieru, AnyTLS,
  TUIC, Snell, SSH, Naive, TrustTunnel, Pingtunnel and WireGuard endpoints.
- Typed option preservation, deterministic overlay precedence, graph retagging,
  malformed input rejection and synchronized form/JSON component tests.

Run the binary-backed tests with:

```
HIDDIFY_CONFIG_CHECK_BINARY=/path/to/hiddify-core-linux-amd64 \
  go test ./internal/web/service -run 'Test(NativeImport|NativeShareOption)' -count=1
```

These checks validate import/configuration construction, not connectivity to remote
VPN servers. Some protocols require additional local dependencies or privileges
when the complete configuration is started.
