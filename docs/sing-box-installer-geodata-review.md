# Проверка установщика и геоданных

Ветка: `update`. Ядро: модифицированный **Sing-box**.

## Исправления

- В интерфейсе, README и актуальных отчётах убрана формулировка про владельца ядра. Закреплённые исходники и build lock не менялись.
- Проверка бинарника из архива выполняется до замены файлов и при новой установке.
- При внешнем или относительном `XUI_BIN_FOLDER` ядро и базы выпуска копируются в настроенный каталог до проверки конфигурации и миграции.
- Сохраняется симлинк `bin`. Откат восстанавливает предыдущие внешние файлы и удаляет новые бинарники и базы выпуска; пользовательские базы сохраняются.
- Обновление Geofiles использует тот же каталог, что просмотр и преобразование правил: `XRAY_LOCATION_ASSET`, затем `xray.location.asset`, затем `XUI_BIN_FOLDER`.
- Загрузка ограничена 256 MiB; после SHA-256 проверяются protobuf-содержимое и тип базы. Повреждённая база с правильной контрольной суммой не устанавливается.
- Ошибка установки второй базы откатывает уже заменённую первую базу. Параллельные обновления сериализованы.
- Замена базы с прежними размером и mtime сбрасывает индекс благодаря проверке идентичности файла.
- Преобразование geosite поддерживает фильтры атрибутов (`@ads@cn`) и алиасы `ext-domain:`, `ext-site:`; GeoIP — `ext-ip:`. Регистр имени файла сохраняется, в том числе для `geoip_RU.dat`.
- Валидатор проверяет фактический тип базы. `geoip:private` использует native matcher и не требует установленного geoip.dat.
- Вкладка «Геоданные» показывает установленные базы, ошибки, категории и записи. Удалены неработающие поля загрузчика Xray, которые сохранялись в шаблоне, но не исполнялись Sing-box.

## Рабочий порядок

Стандартные базы обновляются ежедневно, пока ядро запущено; ручное обновление доступно на вкладке Geofiles. После изменения файлов панель пересоздаёт native-конфигурацию и перезапускает ядро. Обновление без изменения файлов не вызывает перезапуск.

Пользовательские базы `.dat` читаются из каталога геоданных через `ext:имя.dat:категория`. Старый блок `geodata.assets/cron/outbound` загрузчика Xray не выполняется. Для native-конфигурации используется `route.rule_set` Sing-box.

Инверсные GeoIP-токены и базы с `reverse_match` не преобразуются в положительные CIDR: возвращается ошибка. Их следует задавать native-правилом с `invert`. Категории более 500 000 записей также отклоняются; для больших наборов следует использовать native rule sets.

## Проверки и границы

- 15 тестов shell-транзакции, включая внешние пути, свежую установку, относительные пути, абсолютный и относительный симлинк, откат и сохранение пользовательских файлов.
- Go: общий прогон, отдельные тесты геоданных, race detector, vet.
- Преобразованное геоправило проверено через `check -c` на закреплённом модифицированном Sing-box.
- Frontend: typecheck, lint, production build и unit/component tests.

Проверки установщика выполнены в изолированных временных каталогах с тестовыми systemd-командами. Установка на реальном сервере, live PostgreSQL, Docker и фактический сетевой трафик через геоправила в этой среде не проверялись.
