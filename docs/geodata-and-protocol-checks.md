# Геофайлы и проверки протоколов

В редакторе маршрутов sing-box доступны поля GeoSite / geofile, GeoIP назначения и GeoIP источника. Кнопка базы открывает выбор установленного `.dat`, категорий и просмотр содержимого. Можно вводить `geosite:youtube`, `geoip:ru`, `geoip:private` и `ext:geosite_RU.dat:ru-available-only-inside`.

Панель сохраняет ссылки на категории, а при построении конфигурации преобразует их в условия sing-box. После обновления базы используется новое содержимое. Ручные условия сохраняются. Ошибка чтения или пустой результат не превращаются в правило для всего трафика. Во вложенных логических правилах геофильтры задаются в дочерних условиях.

Если задана собственная секция `route` sing-box, неиспользуемая маршрутизация Xray больше не требует чтения её геофайлов. Минимальная автоматическая вставка Gateway продолжает дополнять маршруты Xray.

Ограничение размера файла больше не выдаётся одновременно за неверный тип базы. Потоковое чтение крупных категорий проверяется тестами. Для проверки реального community-релиза:

```sh
GEODATA_TEST_FILE=/path/to/geosite_RU.dat go test ./internal/singbox -run TestOfficialRussiaGeoDataRouting -count=1
```

Проверенный релиз russia-v2ray-rules-dat: `202611162347`, 87 801 052 байта, категория `ru-available-only-inside` содержит 170 записей.

В VetroffProxy автоматический cluster/discovery публикует фактический HTTP/3 UDP-порт, включая отдельный `h3Listen`. Явный публичный адрес сохраняет приоритет.

В TeleMT проверка HTTPS frontend обращается к настроенному WEB-пути. Caddy получает `stream_close_delay`, чтобы перезагрузка сертификата или конфигурации не закрывала установленные WebSocket lanes немедленно.

Проверки выполняются с официальными VetroffProxy `v0.1.0` и Telemt `3.5.17`: конфигурации, запуск процессов, варианты транспорта, WEB-сайты и подписки. Эти проверки не заменяют подключение реального Telegram-клиента через публичный домен оператора.
