# Интеграция модифицированного sing-box

Панель использует собственную сборку `SawaMEN/hiddify-core`, которая в пользовательском интерфейсе и API обозначается **sing-box**. Сохранённое историческое значение `hiddify-core` считывается как `sing-box`; при сохранении применяется каноническое имя.

## Сборка и контракт

Актуальный источник зафиксирован в [hiddify-core-target.json](hiddify-core-target.json). Конфигурация сборки включает точные ревизии ядра и submodules, обязательные Go build tags, overlays и версии библиотек.

Для локальной сборки ядра:

```bash
bash tools/build-hiddify-core.sh /path/to/panel/bin
```

Сборщик проверяет закреплённые источники и зависимости через `tools/verify-hiddify-build.py`, применяет overlays и выполняет проверки версии и конфигурации. Release и Docker используют тот же механизм. Для Naive outbound требуется совместимая `libcronet`.

## Настройка и применение

`internal/hiddify.Runtime` управляет отдельным процессом ядра. Перед применением нового конфигурационного файла выполняется `check -c`. В случае неудачного применения сохраняется предыдущая рабочая конфигурация; ручная остановка ядра не отменяется watchdog.

Адаптер конфигурации формирует native JSON для входящих подключений, пользователей, DNS, маршрутизации, Gateway и подписок. Для статистики используется метод `/v2ray.core.app.stats.command.StatsService/QueryStats`. Повторные опросы не должны повторно начислять трафик пользователям.

При обновлении со старых версий необходимо сохранить резервную копию базы и настройки ядра. Совместимость со сторонними бинарниками не гарантируется: модифицированное ядро и его зависимости должны обновляться согласованно.
