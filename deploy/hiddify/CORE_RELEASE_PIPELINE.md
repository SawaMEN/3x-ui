# Выпуск нативного ядра Hiddify

## Порядок обновления

1. Разработать и протестировать новую функциональность в `SawaMEN/hiddify-sing-box`. Не накладывать изменения из панели повторно.
2. После зелёного CI закрепить tested SHA подмодуля `hiddify-sing-box` в `SawaMEN/hiddify-core`.
3. Проверить native source evidence, команду `check -c`, `srun -c`, version/revision, теги сборки, security pins и компоновку.
4. Собрать Linux AMD64 и ARM64, проверить MASQUE HTTP/1/2/3 и speed broker TCP/UDP; опубликовать архивы, контрольные суммы и `target.json`.
5. В `3x-ui` скачивать стабильный релиз, проверять checksum, источник, теги и arch. На стороне панели отсутствуют patch-файлы для Hiddify.

## Блокирующие проверки

- При отсутствии любого файла `panel_build.native_source_files` и любого `source_checks` сборка останавливается.
- При изменении gitlink, незакреплённой зависимости, ABI или несовпадении `target.json` сборка останавливается.
- Непрохождение MASQUE и реального ограничения скорости не допускает публикации Linux ядра.
- Android необязателен для Linux выпуска и может проверяться отдельно.

Изменения нативных протоколов производятся в ядрах, а не как `git apply` при сборке панели.
