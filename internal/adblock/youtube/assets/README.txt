3x-ui YouTube Companion (Chromium browsers)
================================================

Installation
------------
1. Extract this ZIP archive to a permanent local directory.
2. Open chrome://extensions in a Chromium-based browser.
3. Turn on Developer mode.
4. Select "Load unpacked" and choose the extracted 3x-ui-youtube folder
   containing manifest.json (not the ZIP file itself).
5. Open https://www.youtube.com/ and refresh any already open YouTube tabs.

Usage
-----
Click the extension icon to toggle filtering on or off. Refresh the YouTube
page after changing the setting so the player reloads its scripts.

Scope and limitations
---------------------
This extension modifies selected YouTube player responses and may skip videos
marked as advertisements. YouTube may change its player at any time, so
complete ad removal is not guaranteed. It does not work in the official
YouTube mobile application. The extension uses browser-local storage for
its enable/disable setting and does not require a certificate installation.

To uninstall, remove the extension from chrome://extensions.
